# Fyte: Dataset Description

## Primary Dataset
- **Filename:** `expense_data.csv`
- **Location:** `data/raw/expense_data.csv`
- **Record Count:** 114 entries
- **Temporal Span:** January 2, 2024 to June 30, 2024 (6 calendar months)

## Column Definitions
1. `Date` (String): ISO date string `YYYY-MM-DD`.
2. `Category` (String): Spending category (`Food`, `Shopping`, `Transport`, `Entertainment`, `Health`, `Utilities`).
3. `Amount` (Float): Transaction expense in INR.
4. `Payment_Method` (String): Payment method used (`UPI`, `Credit Card`, `Cash`, `Net Banking`).
5. `Description` (String): Short narration of the transaction.
